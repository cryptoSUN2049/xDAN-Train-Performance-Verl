# 训练记录：分级与节奏

| 级别 | 内容 | 节奏 | 位置 | 写入方 |
|---|---|---|---|---|
| L1 原始快照 | 每次巡检的关键数字（step、最新一步指标、失败数、DSH 结束原因、沙箱、checkpoint、评测状态、报警） | 每 10 分钟 | Mac 本地 `ops/watchdog/snapshots.jsonl`（不进 git） | 看门狗自动写 |
| L2 运行日志 | 每条飞书推送的原文：5 步简报、报警、节点、评测判定 | 每次推送 | `journal/<line>.md` 中标题为「推送」的条目 | 看门狗自动追加 |
| L3 分析记录 | 根因诊断、趋势判断、横向对比、决策和依据 | 每个节点（step 25/50/100、评测结果）、每次事故、每个用户决策 | `journal/<line>.md` 中标题为「分析」的条目 | 训练会话手写 |

- 每一步的完整训练指标已经在 pod 上的 `runs/<run>/metrics.jsonl` 和 W&B 里，这里不重复存储。
- 提交节奏：L3 写完立即提交；L2 随下一次 L3 一起提交，或者每天至少提交一次。
- 文件：`fusion-a.md`（融合线 A 组），`baseline.md`（baseline 线，只读观察）。
- 写 L3 时的规则：只写实测结论，并注明数据口径和时间；推断要明确标出「推断」；先写结论，再写依据。
